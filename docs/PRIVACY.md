# 隐私与数据处理

[返回首页](../README.md)

## 会连接哪里

NexQuota 加载你在本机配置的 HTTPS 账户用量页。服务商网页可能请求它自己的接口、验证码或第三方资源，这些请求遵循网站的行为。

项目没有自建中转服务器、账户同步服务或遥测上传端点。公开文档中的图片、徽章和字体来自仓库或系统，不依赖第三方图片追踪服务。

## 哪些内容留在本机

| 内容 | 存储与用途 |
| --- | --- |
| 站点地址 | 本地配置文件；构建时复制进 App 资源 |
| 登录会话与网站数据 | WebKit 默认持久化数据存储，由 macOS / WebKit 管理 |
| 最近成功用量 | UserDefaults：已用、剩余、周期起止、读取时间 |
| 显示偏好 | UserDefaults：菜单栏模式和刷新间隔 |
| 开机启动 | macOS ServiceManagement 管理登录项 |

缓存不包含 App 保存的原始网页、密码字段值或订阅内容。网页正文会在本机内存中用于状态判断与用量提取，账户页本身仍能显示它提供的个人信息。

WebKit 持久化存储不等同于 NexQuota 对网站内容作额外加密承诺。使用本机账号的访问控制来保护设备及应用数据。

## App 不收集哪些内容

- 不从外部浏览器导入 Cookie。
- 不读取或保存网页密码字段值。
- 不将用量或登录会话上传到项目维护者的服务。
- 不绕过网站的人机验证，不关闭 HTTPS 证书检查。

## 截图与公开仓库

公开图片从本项目的原生 SwiftUI 视图生成，使用固定的 125 GB 已用 / 375 GB 剩余演示数据。生成过程不创建 WebSession，不访问服务商，不读取真实账号或本机浏览器会话。

图片不包含邮箱、账号、密码、Cookie、Token、私人站点查询参数、桌面内容或其他 App 的窗口。封面的菜单栏背景是文档排版示意，见 [图片来源说明](assets/README.md)。

`Config.local.plist`、构建目录、私有截图目录、常见凭据文件与日志被 Git 忽略。忽略规则不能保护已被主动提交的文件，发布前仍应检查待提交文件。

## 反馈问题时

请用虚构样本、裁切后的单个 App 视图或经过脱敏的页面结构反馈。不要贴完整订阅地址、登录请求、Cookie、邮件地址或未处理的网络日志。涉及敏感数据的问题按 [安全报告说明](../SECURITY.md) 处理。

## 删除与退出

关闭账户窗口不会注销会话，便于后台刷新。移除 App 文件不会自动清除 WebKit 或 UserDefaults 数据。网站退出登录与本机数据清理属于不同操作；按自己的需要分别处理。
